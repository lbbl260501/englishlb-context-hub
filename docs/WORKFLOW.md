# 讲义与学习记录流程

## 选题

从尚未覆盖的具体问题中选择文章；主题标签只用于组织，不是频率或命题预测。先核验真题、参考答案和词义，再决定词汇名单。

## 去重

lexemes 的 primary_lesson 与 exposures 的 primary 记录必须一致。历史样章 S001 同样参与。运行 plan_next，查看候选是否已主讲。重复词只能进入复习或有说明的新义项扩展；不要为了消除警告删掉历史记录。

## 编写与发布

练习 → 答案解析 → 双语附录。为每个来源注明类型与位置。新增词汇写入 lexemes，正式主讲后才登记 primary exposures 和 primary_words；规划候选不可提前登记。新增义项另记 sense_note 和证据。校验所有关联 ID，再检查 PDF 内容与版面。

## 收尾

更新 lessons、exposures、sources 和 sessions；实际测验另写 assessments。运行 audit、plan_next 和 build_snapshot。提交后报告真实 commit 和未完成项。若仅在聊天中生成内容，必须交付待提交文件，不能说仓库已更新。
