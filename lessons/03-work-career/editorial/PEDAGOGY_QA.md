# L003 学生讲义教学质量复核｜2026-10-11

> 这是**编辑者内部质量记录**，不放进学生 PDF。本次复核对照实际生成的 L002 46页 LaTeX 学生版与 L003 50页 LaTeX 学生版；不把页数和词汇数等同于教材质量。L003 仍是 `planned`，未据此增加已教词汇。

## 判断

**L003 较 L002 更不适合独立学习，需重做核心教学环节后发布。** 这属于具体教材的比较判断，不等于已对学习效果完成实验测定。

1. **读前情境不够贴近学习困难。** L002 从跨行政边界的水污染和历史低强度野火进入阅读，学生可以先建立因果画面；L003 直接引入学位贬值、劳动申诉、企业生产率等抽象机制，缺少供初次阅读者使用的人物/时间/因果示意。
2. **词汇讲解明显模板化。** L002 的23项“读题提醒”按词设置不同误读；L003 的28项“自检”仅使用两套提示，各重复14次，无法区分 `be found wanting` 的被动评价、`social mobility` 的概念义与 `procedural` 的用法。
3. **没有独立的“学词后返回真题”实践段。** L002 第一单元在词汇后安排“把词重新放回文章”并设4个根据具体词/文章论证解答的问题。L003 把“放回真题”写成28条解释性说明，却很少让学习者以词汇为工具重新回答真题中的原句和选项。
4. **解释先于自主验证的风险。** L003 Text 2在第6页的“真题选项究竟改写了什么”直接列26–30参考答案，后面才进入14项词汇；Text 4在第13页先给全部36–40答案，后面才开始第二组词汇。虽然导读要求初次先做真题，但章节内部缺少与答案分离的“二次独立定位题”，便于不小心提前看见解答。
5. **题量与教学目的脱节。** L003两篇自编阅读、46道原创练习虽然数量更多，但偏重 `may / not necessarily / not always / evidence limited` 等重复的范围判断。应加入原文句法拆解、事实定位、主旨归纳、指代追踪、同义改写的渐进难度，而不是同一种“反绝对化”反复出现。
6. **版面问题。** L003第11、18、23、26、30页主体内容较少、空白较大；词汇长列表连续多页密集排印，造成费力的阅读节奏。L002的独立词汇卡片更易按词学习，但也不是完美标准，仍应进一步减少无意义空白与增强阅读标注。

## 下次改版的可验收要求

**顺序修订：** 
读前一页背景（不泄露答案）→首次限时完成原卷→每篇按2–3个关键段落分解（问题-读原句-句法-义项-解释）→小练习→其余词汇补充→第二次无提示完成真题的“证据定位＋选项改写”→原创迁移→答案→英中对照。

**重点词深讲+剩余词简讲：**
优先对 `be found wanting`, `devalue`, `social mobility`, `scrap`, `threshold`, `grievance`, `procedural`, `constrain` 做专门学习任务；其余词以不同难度的接触+复现补全覆盖。不能按词条统一两句+同一个“自检”模板。

**真实词汇回流：** 每讲3–5项词汇后，必须有至少一道针对相应真题段落的“去找原句→看结构→说明这词决定了何种判断”的活动，而不只是词条后写“放回真题”。

**干扰项逐项讲解：** 对选项解释“哪句话提供证据，干扰项改变了对象、范围、方向还是作者立场”，不写“无中生有”就结束。

**双语及编辑分离：** 保留LaTeX和答案后的全文英中对照；所有来源/版权/词条ID/质量数据留在编辑档案，不混进学生版。

**发布前检查：** 两套文档每册各随机抽取10个单词，让审核者判断学生不看解释能否完成任务；至少核对全部真题选项、原创题答案、中译；对PDF逐页审视空白率及章节顺序。尚未同步教材全文件到仓库前，保持L003未发布及候选词不计已教。

## 示范：重做 be found wanting

教学入口：2022英语（一）Text 2，P2。紧邻表述为：
- “But that promise has been found wanting.”
- “As degrees became universal, they became devalued.”

请学生先找 **that promise** 所指的“持有学位便能获得一生稳定就业与回报”的既有社会期待，然后判断 **found wanting** 是“（这一承诺）被证明未能达到预期”，而不是“学生想得到某样东西”。进一步讨论：**devalued** 指学位作为区分信号的相对价值减弱，**不等于**教育或所有学位已经失去全部价值。最后让学生解释真题第27题 B 的“shrinking value of a degree”与原文哪个判断意义相通，再在新例句中无提示辨析。完整中译统一归入文末附录。
